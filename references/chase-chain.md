# 追链范例：一条链怎么追、追到哪停

「追链」是这个 skill 的核心动作。这份文件给出**方法**和**三类实例**。

---

## 方法：一把尺子量到底

每个候选知识点，都要能回答一句话：

> 「**它跟"用户要解决的那件事"什么关系？**」

- 答得上 → 留在链上
- 答不上 → **砍**（进"以后再说"）

**追到哪停？** 追到"用户本来就懂"的那一层为止。再往下是常识，不用补。

---

## 实例 1 · 概念类：「这段 CSS 里的 `flex: 1` 是啥？」

- **要解决的事**：让两个盒子并排、不挤在一起。
- **追链**：懂 `flex:1` → 得先懂 `flex`（弹性布局）→ 得先懂"网页元素默认是往下摞的" → 到头（常识）。
- **链**：默认往下摞 → 外层加 `display:flex`（横着站队）→ `flex:1`（每人占一份）
- **砍掉**：`justify-content`、`align-items`、`grid`

## 实例 2 · 判断类：「我嘴唇有点白」

- **要解决的事**：这算身体信号，还是自己多想？
- **追链**：判断"严不严重" → 得知道唇白有哪些可能 → 得知道**唇色是怎么来的** → 到头。
- **链（4 段）**：
  1. **根**：唇色 = 皮下血管里的血透出来的颜色（**最关键、也最常被跳过的一环**）
  2. **因**：变白只有三条路 —— 血少（贫血）/ 血不来（循环差）/ 天生浅
  3. **判据**：看别处（眼睑、指甲、手掌）白不白 + 是不是一阵一阵 + 有没有伴随症状
  4. **行动**：什么情况别扛、去医院查什么
- **砍掉**：贫血分类、血红蛋白机制、各型治疗、食补
- **红线**：医疗场景 → 必须自报边界（"我不是医生"）+ 只给方向 + 留出口。

> **这个例子最关键的一点**：大多数人回答这题，张口就是"贫血分几种"——**那是枝叶**。
> 用户要的是判断，不是学血液学。**要补的，是根。**

## 实例 3 · 报错类：「这行代码报错：Cannot read property 'map' of undefined」

- **要解决的事**：让这行代码跑通。
- **追链**：懂这个报错 → 得先懂"`undefined` 表示这里根本没东西" → 得先懂"你拿到的不是一列数据，而是空" → 到头。
- **链**：`undefined` = 没东西 → `.map()` 是要对"一列东西"逐个操作的 → 对空用 `.map()` 就炸 → 所以第一件事是看这个变量到底是不是空的
- **砍掉**：JS 类型系统、数组方法全集、异步加载顺序
