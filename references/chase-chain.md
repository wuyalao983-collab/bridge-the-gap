# 追链方法（找到你卡在哪）

"追链"就是：从"你要用的那个知识"往回退，一级一级问——想懂这个，得先懂啥？退到"你本来就懂"为止。中间缺的那几环，就是要补的。

## 怎么追（心里问自己）

- 想懂 B，得先懂 A 吗？-> 要，就记下来。
- 想懂 A，得先懂啥？-> 退到"这他本来就会 / 是常识"为止。
- 从"要用的"到"本来就会的"之间，缺的几环 = 这次全部要补的。

## 三类实例，断点长不一样

### 1. 概念类（一个词 / 说法不懂）
断点通常是"比喻或黑话"。
- 招式：**先把这个词翻译成人话**，再补它存在的理由。
- 例："用户画像" -> 翻译：把人分堆贴标签；理由：为了精准推送。

### 2. 症状类（身体 / 设备出了个现象）
断点通常是"现象 <-> 背后那个量"的关系。
- 招式：先把"现象"和"它靠什么撑着"连起来，再分"一时的 vs 该查的"。
- 例：嘴唇白 <-> 血氧 / 铁。医疗 / 法律 / 金融类走红线三件套（自报边界、只给方向、留出口）。

### 3. 报错类（代码 / 系统报错了）
断点通常是"某个值现在是空的 / 类型不对，却被当成别的在用"。
- 招式：先翻译报错里那个词（`undefined` = 空、`null` = 空、`TypeError` = 类型不对），再指出"它以为 X 是 Y，其实 X 是 Z"。
- 例：`undefined` + `.map` -> 对着空列表要逐个处理。

## 硬规则

- **链通即停**：能连起来就收，不卡补了几个。
- **不碰无关**：追的时候撞上"跟他这道坎没关系"的，砍掉，记一句"以后再说"，不展示。
- **不考他**：追链是你心里过的，别把它变成"你先说说看 A 是啥"的提问。
