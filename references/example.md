# 示例：一次完整的「拐棍」

这份示例展示 skill 跑起来的样子。AI 读它，是为了对齐**输出的形态和语气**。

---

## 场景

- 人物：小周，中专毕业，刚开网店，自己在改店铺页面。
- 情境：他让 AI 帮忙调页面排版，AI 给的代码里有一行 `flex: 1;`。
- 他说：**「这个 flex: 1 是啥？我看不懂。」**

---

## AI 走一遍

### Step 1 · 问一句（定界）

> 你是想把这块布局**调出来**，还是想弄明白 `flex` 到底在干嘛？

小周：「就想让这两个盒子并排、别挤在一起。」

（AI 记下：目标是「让两个盒子并排」。范围就是这一件事。）

### Step 2 · 追链

从"要用的知识"往回追：

- 想懂 `flex: 1` -> 得先知道什么是 `flex`（弹性布局）。
- 想懂 `flex` -> 得先知道网页排版的两种基本摆法（一个个摞着 / 一排横着放）。
- 再往回 -> 到头了，这是常识级的，不用补。

**断点找到了**：他缺「弹性布局」这一环。

### Step 3 · 补环

只补「`flex` 是干嘛的」这一环。**不碰** `justify-content`、`align-items`、`grid` 这些（跟"让两个盒子并排"没关系），记进"以后再说"。

### Step 4 · 大白话讲通

> 网上的东西默认是**从上往下摞着放**的，像叠积木，一个压一个。
>
> 你给外面的盒子加一个 `display: flex`，就等于跟它说：**"里面这几样，改成横着排，像并排站队。"**
>
> 那 `flex: 1` 呢？它写在**里面每个小盒子**身上，意思是：**"你们几个，平均分这块地盘。"**
> 谁写 `flex: 1`，谁就占一份。两个都写 `flex: 1`，就是一人一半，谁也挤不着谁。
>
> 一句话：**外面说"横着站队"，里面说"每人占一份"。齐活。**

（自检：一个初中生能看懂吗？—— 能。）

### Step 5 · 收工 + 落库

讲完，停。不问"懂了吗"，不出题。

存入独立库 `walking-stick/flex布局.md`：

```markdown
# flex 布局

- 他遇到的坎：改店铺页面，想让两个盒子并排、别挤在一起，看不懂 `flex: 1`
- 链：默认从上往下摞着放 -> 外层加 display:flex（横着站队）-> flex:1（每人占一份）
- 讲通了：外层说"横着站队"，里面说"每人占一份"，两个都写 1 就是一人一半。
- 以后再说：justify-content（管队怎么对齐）、align-items（管上下居中）、grid（更复杂的格子排版）
- 标签：#前端 #CSS #排版
- 日期：2026-10-10
```

---

## 这个示例守住了什么

| 规则 | 怎么守住的 |
|---|---|
| 不考试 | 讲完就停，没出题 |
| 不发散 | 只讲 flex，没碰 grid / 对齐 |
| 大白话 | 用"站队""分地盘""叠积木"，零术语 |
| 事前提问 | 只问了一句，就一句 |
| 链通即停 | 补到"能并排"就够了 |
| 独立落库 | 存进 walking-stick/，没动第二大脑 |
