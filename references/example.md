# 完整走一遍（范例）

下面三局，都是真有人会问的。每局都按 SKILL.md 的流程走：定界一句 -> 追链 -> 补环 -> 大白话讲通 -> 落库 -> 签名。
追链那一步是"我（agent）在心里过的"，不念给用户听；只把结果用大白话讲出来。

---

## 例 1 · 概念类（老板说要做"用户画像"）

**用户原话：** 老板说要做个"用户画像"，这是啥？

**定界（一句）：** 你是想搞懂它啥意思，还是要拿它去交差 / 干活？
（他答：都要，先懂再干 -> 那就先讲懂，不顺手替他做。）

**追链（心里过）：** 用户画像 -> 把一类人按特征描述出来 -> 为了知道"该对谁说啥" -> 本质是"给一群人贴标签、分堆"。他卡在"画像"这个比喻不懂。断点 = 画像 = 分堆贴标签。

**讲通（大白话）：**
> 别被"画像"俩字唬住。它说的不是画一张脸。
> 说白了：你有一堆用户，你按"他们是谁、爱干嘛、肯花多少钱"给他们分堆，每堆贴个标签——比如"爱熬夜的学生党""精打细算的宝妈"。
> 老板要的"用户画像"，就是这些标签 + 每堆人的特征。有了它，才知道该对谁推啥、说啥话。

**落库卡片：**
- 他遇到的坎：不懂"用户画像"是啥
- 链：分堆贴标签 -> 每堆特征 -> 用来精准推送
- 讲通了：（上面那段）
- 以后再说：怎么采集数据做画像（超出这道坎，没碰）
- 标签：#概念 #运营 #用户画像

**签名（固定收尾）：**
> **你缺的那一环是：画像 = 把人分堆贴标签，补上就能用了。**

## 例 2 · 症状类（嘴唇发白 · 含专业红线）

**用户原话：** 我嘴唇有点白，是咋回事？

**定界（一句）：** 你是想先弄明白可能的原因，还是要我直接教你怎么去查？
（他答：先弄明白 -> 讲方向，不替医生下结论。）

**追链（心里过）：** 唇色 <-> 血氧 / 铁 -> 一时性的（冷 / 累 / 没睡）vs 该查的（贫血等）-> 断点 = 唇色和血氧 / 铁的关系。

**讲通（大白话 + 红线三件套）：**
> 嘴唇的颜色，是靠血里的氧撑着的。血氧不够，或者血里运氧那个"铁"不够，嘴唇就会发白。
> 所以分两种：一种是**一时的**——冻着了、累着了、没睡好；一种是身体在**提醒你该查一查**。
> ——我不是医生，不能替你判断是哪一种。想弄清楚，去医院挂**血液科**，跟医生说：
> 「唇色发白，想做个**血常规 + 铁蛋白**。」

**落库卡片：** 同上结构，标签 #症状 #医疗红线。

**签名：**
> **你缺的那一环是：唇色 <-> 血氧 / 铁，补上就能用了。**
> （要确诊，去找医生，上面的话是帮你开口，不是结论。）

## 例 3 · 报错类（Cannot read property 'map' of undefined）

**用户原话：** 这行代码报错：Cannot read property 'map' of undefined

**定界（一句）：** 你是想搞懂为啥报这个错，还是要我先帮你把它修好？
（他答：先懂为啥 -> 讲透原因，不替他改。）

**追链（心里过）：** undefined = 空 / 没东西 -> .map 是对"一列表"逐个数处理 -> 对着"空"要逐个数 = 没东西可数 -> 断点 = 变量此时是空的，却在当列表用。

**讲通（大白话）：**
> `undefined` 就是说"这儿啥也没有、是空的"。
> `.map` 是"把一个清单里的东西，一个个拿出来处理"。
> 你对着一个**空**的东西，要"一个个拿出来"——当然拿不到，就报错了。
> 所以根因就一句：那个变量**这时候是空的**，你却当它是一串列表在用。先把"它是不是空的"确认了，再 `.map`，就不报了。

**落库卡片：** 标签 #报错 #代码 #JavaScript。

**签名：**
> **你缺的那一环是：对着 undefined（空）调 .map = 没东西可数，补上就能用了。**
